Aegis OS (aegis-os) · 事务型多租户 Agent 操作系统运行时

以 Rust 构建的本地与云端智能体内核运行时：用事务型写时复制（CoW）影子工作区、双层 OS 内核沙箱、L7 零信任出站网关与五阶段策略引擎，彻底终结自主 Agent 的“授权弹窗疲劳”。

6.3 ms macOS APFS clonefile 影子工作区克隆（98.7% 自动合并）
0.0% ASR 80 项对抗性越权与凭据窃取攻击下攻击成功率为零
-90.7%~97.9% 28,087 次真实工具调用下的人工授权中断削减比例
  • 事务型 CoW 虚拟文件系统 (aos-vfs)：基于 APFS clonefile(2) 与 Linux FICLONE 为每个 Agent 分配隔离影子工作区，4 级 LCS Diff3 自动变基合并与提交前门禁校验。
  • 双层操作系统内核沙箱 (aos-sandbox)：动态编译 macOS Seatbelt SBPL 与 Linux Bubblewrap 命名空间策略，默认拒绝读取 ~/.ssh、~/.aws 等敏感宿主目录。
  • 零信任 L7 密钥代填与出站 DLP (aos-egress)：Agent 仅持 $AOS_SECRET_* 占位符，由可信网关在方法/路径校验后注入真实凭证并拦截私钥/Token 外泄。

WHY HEURION

通用 AI 无法支撑严肃临床科研，卡在四个关键环节。

01

数据孤岛与隐私失控

病历、纸质化验单与随访表格散落在各处，缺乏结构化标准，直接输入外部大模型存在严重隐私泄露风险。

Heurion：多模态 OCR 结构化提取，知家 PHR 闭环归档，内置 PHI 敏感信息扫描拦截与多级脱敏授权。

02

队列圈定与分析断层

从海量病历中人工筛选符合复杂入排条件的队列耗时数周，统计分析需要频繁在 SPSS/Excel 与文稿间手动搬运。

Heurion：可视化高级队列筛选器秒级圈定样本，AI 在隔离受限沙箱直接生成 Table 1 基线表与统计图表并写入文稿。

03

课题记忆断代与反复交代

课题研究假设、统计定义和团队共识散落在聊天记录里，每次更换会话或新成员加入都要从头重新交代背景。

Heurion：课题自主记忆演进引擎，自动提炼偏好与常用事实，人类确认后持续生长，自动合并、更新与淘汰知识。

04

引用凭空捏造与改动黑盒

传统生成式 AI 常凭空编造不存在的假文献，一键改稿直接覆写整篇文档，改了哪里、为什么改完全看不清。

Heurion：引用文献经 PubMed / Crossref / OpenAlex 核验，写前守卫以行内高保真差异修订呈现每一个字符的修改。

Heurion 是专为医学与科研打造的辅助工作台，严格守护患者隐私与研究合规。平台不提供诊断或治疗建议，AI 生成内容须经作者审阅确认。

  • 受限沙箱环境

    AI 编写的统计分析代码在独立的受限系统用户中运行：出站网络只放行平台内部端口，不能直接访问数据库、平台密钥或他人工作区。

  • PHI 敏感信息扫描

    内置个人健康信息（PHI）扫描工具，可在数据与文稿中检出并脱敏未经处理的姓名、身份证号、手机号与病案号等。

  • 密钥不出平台

    大模型调用经平台代理转发，隔离执行环境内只拿到短期有效的访问令牌，接触不到真实的模型 API 密钥。

  • 受控记忆与完整审计

    AI 记忆仅能以“提议”形式生成，生效权完全属于作者；系统全程记录患者数据访问、分析执行与文件导出的合规审计日志。

* Heurion 不是医疗器械，不用于临床诊断、治疗决策或预后判断；医疗机构部署前请按照当地医疗数据合规法规完成评估。

FLAGSHIP 02 DEEP-DIVE · AEGIS OS KERNEL RUNTIME

Aegis OS：为自主编程与科研 Agent打造的事务型操作系统运行时。

当 Claude Code、Cursor、Gemini CLI 或科研子智能体在真实代码库与数据集中并发执行时，传统终端面临“逐次弹窗疲劳”或“全量放行（--dangerously-skip-permissions）导致宿主损毁与密钥泄露”的两难。Aegis OS 以四大 Rust 内核子系统在操作系统层彻底化解这一悖论。

01 · crates/aos-vfs

事务型写时复制虚拟文件系统 (Transactional CoW VFS)

利用 macOS APFS clonefile(2)（6.3ms）与 Linux Btrfs/XFS FICLONE（15.6ms）为每个智能体提供毫秒级零拷贝影子工作区。所有文件修改均先落在隔离影子层，经 4 级 LCS Diff3 自动变基合并（98.7% 自动收敛率）并通过提交前测试门禁（verify_cmd）后，方可原子提交至宿主仓库。

02 · crates/aos-sandbox

双层操作系统内核沙箱 (Seatbelt & Bubblewrap)

按智能体工作区动态生成 macOS Seatbelt SBPL 与 Linux Bubblewrap 用户命名空间规则。内核级强制只读挂载宿主仓库、只写挂载影子工作区，并默认拒绝读取 $HOME 下的 ~/.ssh、~/.aws、~/.gnupg 与浏览器凭据（80 项红队攻击 0.0% 逃逸率）。

03 · crates/aos-egress

零信任 L7 密钥代填与出站防泄漏网关 (Egress DLP)

智能体进程环境变量中不存留任何明文 API Key，仅持有不透明占位符 $AOS_SECRET_*。出站 HTTP 请求须经可信 L7 代理校验目标域名、HTTP 方法与路径白名单后方可代填真实凭证，同时实时扫描拦截 PEM 私钥、AWS AKIA 与 Bearer 令牌外传。

04 · crates/aos-policy & aos-ipc

五阶段策略引擎与 Google A2A / MCP 协同总线

确定性五阶段（R0a–R4）Cedar 风格策略引擎配合时序能力租约（Capability Leases），在 28,087 次真实工具调用中消除 90.7%–97.9% 授权确认弹窗；内置 35 项 MCP 原语、推送式语义文件锁（coord_claim）与 SHA-256 寻址 CAS 工件总线（跨 Agent Token 消耗降低 99.85%）。

FREQUENTLY ASKED QUESTIONS

关于 Heurion，临床研究者常问的问题。

了解 Heurion 的技术架构、医学影像能力、隐私合规保障以及与通用大模型的本质区别。

Heurion 是什么？与普通通用大模型（如 ChatGPT / Claude）有什么本质区别？

Heurion 是专为医学与临床科研打造的全流程 AI 智能工作台，覆盖患者数据录入、课题组纳排、MONAI 3D 影像量化、发表级 Table 1 三线表生成与论文写作全生命周期。

与通用大模型相比，Heurion 针对临床科研的几个痛点：1) 引用核验：引用经 NCBI PubMed 与 Crossref 核对，无法核实的 DOI/PMID 会被标出；2) 3D 医学影像：集成 Project MONAI 与 PyTorch，支持 CT/MRI 体数据分割、RECIST 1.1 径线与体积测量和三正交 MPR；3) 患者隐私：入组即分配 S001... 去标识编号，AI 统计代码在无外网访问的受限沙箱中运行；4) 统计与发表级输出：在沙箱中运行 Python 统计脚本，一键生成发表级 Table 1 原生 Word 三线表（1.5pt/0.5pt 边线）与 CONSORT 2010 流程图。

Heurion 如何保障患者健康隐私（PHI）与医疗数据安全？

Heurion 的数据保护措施：1) 去标识：入组患者自动分配学术编号（S001、S002...）；2) PHI 扫描：内置基于规则的扫描器，可在数据与文稿中检出并脱敏姓名、身份证号、手机号与病案号；3) 沙箱隔离：AI 执行统计分析的 Python 环境运行在独立的受限系统用户中，出站网络只放行平台内部端口，不能直接访问平台数据库或他人工作区；4) 大模型调用：AI 对话经平台代理调用外部大模型服务，建议只提交已去标识的数据。

Heurion 支持哪些医学影像（CT/MRI）智能分析模型？

Heurion 影像分析服务集成 Project MONAI 与 PyTorch，支持 NIfTI 与 DICOM 格式。已在公开数据集样本上实际运行的能力包括：1) 脾脏自动分割与体积测量（MONAI 官方 spleen_ct 3D-UNet 权重）；2) 基于分割掩膜的 RECIST 1.1 最长径与体积测量；3) 三维影像组学特征提取（形状、一阶统计、GLCM、GLRLM 共 46 项）；4) 三正交多平面重建（MPR）。所有输出仅供科研参考，不构成诊断意见。

Heurion 如何帮助临床医生撰写医学论文与准备投稿材料？

Heurion 覆盖论文发表常用的材料：1) 导出发表级 Table 1 原生 Word (.docx) 三线表，可给出两组间 SMD；2) 绘制 CONSORT 2010 / STROBE 受试者流向矢量图；3) 计算 VanderWeele E-value 未测混杂敏感性指标；4) 运行 Kaplan-Meier 生存曲线与 Cox 比例风险回归；5) 核对论文中的文献引用、效应量（HR/OR/RR）与 95% 置信区间。

如何通过 MCP (Model Context Protocol) 将 Heurion 接入其他自主 AI Agent？

Heurion 提供了符合 Anthropic Model Context Protocol (MCP) 标准的专用服务端点，支持 Claude Desktop、Cursor、Cline 等自主 AI 智能体接入。Agent 可通过标准化工具调用 Heurion 的文献核验、医学影像切片提取、受试者纳排、沙箱统计分析与文档协同创作能力。

Aegis OS 是什么？它与 Heurion 2.0 临床工作台如何协同工作？

Aegis OS (aegis-os) 是 Heurion Research 研发的事务型多租户 Agent 操作系统运行时（基于 Rust 构建）。它为自主智能体提供毫秒级 APFS/FICLONE 写时复制（CoW）影子工作区、macOS Seatbelt 与 Linux Bubblewrap 双层内核沙箱（80 项红队攻击 0.0% 越权率）、L7 零信任密钥注入与出站 DLP，以及 Google A2A / MCP 协同总线（消除 90.7%–97.9% 授权确认弹窗）。Heurion 2.0 原生实现 AAP-1.0 协议，可通过 aegis app install https://heurion.org 直接挂载到 Aegis OS 中安全运行。
