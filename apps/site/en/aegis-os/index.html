FLAGSHIP 02 · RUST · TRANSACTIONAL MULTI-AGENT OS

Aegis OS
Transactional multi-agent control plane

Aegis OS lets multiple coding agents (Claude Code, Codex, AGY) run safely in parallel: each agent gets its own CoW shadow workspace and kernel sandbox, collaborates through Google A2A, requests personal memory through UOMP, and can offload heavy builds to 64GB cloud workspaces in one command.

01 / ISOLATION

CoW Workspaces & Sandbox

Each agent gets a millisecond APFS clonefile / Linux FICLONE Copy-on-Write shadow workspace and OS kernel sandbox with 0 prompts for in-sandbox work.

02 / COLLABORATION

Google A2A Coordination

Built-in AgentCard discovery, task state machine, advisory file claims (coord_claim), and 4-tier LCS Diff3 auto-merge across parallel agents.

03 / CONSENT & TOTP

Boundary & Memory Consent

Host commits (workspace_commit) require explicit human or phone TOTP approval; UOMP personal memory access is scoped by tag/key and revocable anytime.
