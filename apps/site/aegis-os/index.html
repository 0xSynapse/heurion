Aegis OS
本地多 Agent 控制平面

Aegis OS 让多个 coding agent 在同一台机器上安全并行：每个 Agent 有自己的 CoW 工作区， 通过 Google A2A 协作，通过 UOMP 请求用户记忆，所有越界操作都要经过任务级租约、审批、撤销与审计。

从安装到第一个任务 → GitHub 仓库 →

01 / ISOLATION

隔离

每个 Agent 一个 CoW 影子工作区；macOS Seatbelt / Linux Bubblewrap 沙箱；默认拒绝宿主凭证与越界写入。

02 / COLLABORATION

协作

Google A2A AgentCard、Task 生命周期、peer registry、文件 claim 与 Live Collaboration Radar。

03 / CONSENT

同意

UOMP 记忆同意协议：按 tag / key、时限、可撤销；高敏数据逐 key 批准；本地 trusted consent UI 自动弹出，无需另开终端；每次 allow / deny 都有审计。

INSTALL

安装 Aegis OS

支持 macOS 与 Linux。Windows 不在支持范围内。安装脚本会自动把 Aegis OS 接入 agy、claude 与 codex。

# Homebrew
brew tap heurion-org/aegis-os https://github.com/heurion-org/aegis-os.git
brew trust heurion-org/aegis-os
brew install aegis-os

# 验证
aegis-os --version
aegis-os doctor

如果你不用 Homebrew，可以从 GitHub Releases 下载对应平台的二进制，或从源码构建。安装后如未自动接入客户端，运行一次 aegis-os install。

FIRST RUN

第一次运行

01

在项目目录启动 Agent

直接运行 claude、codex 或 agy。Aegis OS 的 hook 会自动附加运行时；首次运行会让你选择 Local（免费本地）或 Cloud（Aegis Cloud）模式。

02

让 Agent 在隔离工作区里工作

Agent 的写入先落在 CoW 影子工作区；workspace_commit 才把变更合并回宿主目录。多个 Agent 并行时，文件 claim 会阻止静默覆盖。

03

需要记忆时，明确批准

Agent 通过 UOMP 请求你的笔记。Aegis OS 会自动打开本地同意页；你勾选 tag / key 后 Allow 或 Deny。不需要另开终端，Agent 也不能批准自己的请求。

04

随时撤销并查看审计

aegis-os memory revoke <session-id> 立即收回访问；绑定的 A2A task 会转为 input-required。每次 allow / deny 都记录在 aegis-os memory audit。

CORE COMMANDS

常用命令

# 安装检查
aegis-os doctor

# 记忆：导入、配置客户端、启动本地服务
aegis-os memory setup claude --vault ~/Notes

# 同意页（通常自动打开；手动打开用这个）
aegis-os memory ui

# 终端 fallback
aegis-os memory pending
aegis-os memory approve <request-id>
aegis-os memory audit
aegis-os memory revoke <session-id>

# 多 Agent：A2A task 与任务看板
aegis-os ipc request --to worker --subject "Review auth" --message "Read the auth module"
aegis-os a2a board
aegis-os a2a show <task-id>

# 任务级租约（高级）
aegis-os policy lease --action-pattern workspace_commit --ttl-secs 3600 --task-id <task-id>

如果使用自定义 --runtime-dir，a2a board、a2a show、memory revoke 等命令要传同一个 runtime 目录。
