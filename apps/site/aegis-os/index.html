FLAGSHIP 02 · RUST · LOCAL & CLOUD AGENT OS RUNTIME

Aegis OS
多 Agent 隔离运行时与云端沙箱

Aegis OS 让多个 coding agent（Claude Code、Codex、AGY）安全并行：每个 Agent 拥有独立的 CoW 影子工作区与内核沙箱， 支持一键切换至 64GB 零本机负载云端运行时，通过 Google A2A 协作，通过 UOMP 请求用户记忆，所有越界操作均经由零终端切换审批、任务级租约与审计。

从安装到第一个任务 → 云端控制台 / 订阅 Pro ($29/月) → GitHub 仓库 →

01 / ISOLATION

隔离

每个 Agent 一个 CoW 影子工作区；macOS Seatbelt / Linux Bubblewrap 沙箱；默认拒绝宿主凭证与越界写入。

02 / COLLABORATION

协作

Google A2A AgentCard、Task 生命周期、peer registry、文件 claim 与 Live Collaboration Radar。

03 / CONSENT

同意与边界审批

越界提交自动弹出 /approve 网页审批台（批准后自动续跑，或运行 aos approve）；UOMP 记忆同意按 tag / key 最小授权并全程审计。

01 / INSTALL

安装 Aegis OS

支持 macOS 与 Linux。Windows 不在支持范围内。Homebrew 安装二进制后，运行一次 aegis-os install 完成 agy、claude 与 codex 的接入。

# 方式 A：Homebrew（macOS & Linux）
brew tap heurion-org/aegis-os https://github.com/heurion-org/aegis-os.git
brew install aegis-os
aegis-os install

# 方式 B：一行签名校验安装脚本（自动完成 aegis-os install）
curl -fsSL https://heurion.org/aegis-cloud/install.sh | sh

# 验证客户端挂载状态
aegis-os doctor

如果你不用 Homebrew，可直接运行上方一行安装脚本，或从 GitHub Releases 下载对应平台的二进制后运行一次 aegis-os install。

02 / LOCAL VS. CLOUD RUNTIME

本地免费模式 vs. Aegis Cloud 线上运行时

两套模式向 Agent 暴露完全一致的 38 个 MCP 工具与 CoW 事务语义。日常默认静默启用本地免费模式；当你需要多 Agent 重型并发编译、本地零风扇噪音时，可随时挂载至 64GB 线上运行时：

LOCAL COMMUNITY · $0 永久免费

本机 CoW 影子工作区 + 免费云端体验档

安装后直接启动 claude、codex 或 agy 即可静默运行在本机 APFS/btrfs CoW 沙箱；或运行 aegis-os cloud up 挂载免费线上体验工作区（1 个并发 Agent · 200 次调用/日）。

# 默认直接使用本机 CoW 沙箱，或挂载免费云端工作区：
aegis-os cloud up
AEGIS CLOUD PRO · $29 / 月

64GB 线上安全 OS 运行时 · 8 个 Agent 并行

0% 本机 CPU/RAM 负载，支持最多 16 个线上工作区、8 个并行 Agent、每日 20,000 次系统调用与 10 小时 64GB 沙箱算力，本地修改自动增量同步，越界提交支持 TOTP 手机验证码审批。

# 终端一行命令完成订阅、认领密钥并挂载当前目录：
aegis-os cloud subscribe --plan pro --wait

03 / FIRST RUN

第一次运行

01

在项目目录直接启动 Agent

直接运行 claude、codex 或 agy。Aegis OS 的 hook 会自动挂载运行时并默认进入免费本地 CoW 模式（零打扰，无需首次配置弹窗）。

02

在隔离工作区编码，越界提交一键批准

Agent 的读写与测试全部在 CoW 影子工作区内 0 弹窗执行；当调用 workspace_commit 写回宿主机时，桌面环境会自动弹出 /approve 网页审批台（批准后自动续跑），纯终端/SSH 下也可运行 aos approve 一键放行。

03

需要记忆时，明确批准

Agent 通过 UOMP 请求你的笔记。Aegis OS 会自动打开本地同意页；你勾选 tag / key 后 Allow 或 Deny。不需要另开终端，Agent 也不能批准自己的请求。

04

随时撤销并查看审计

aegis-os memory revoke <session-id> 立即收回访问；绑定的 A2A task 会转为 input-required。每次 allow / deny 都记录在 aegis-os memory audit。

04 / CORE COMMANDS

常用命令

# 安装检查与多 Agent 实时看板
aegis-os doctor
aegis-os top

# 边界审批（自动识别 Local / Cloud 模式与最新待批请求，支持简写 aos approve）
aegis-os approve
aegis-os approve --web

# 云端运行时：一行命令订阅 Pro ($29/月) 或切换云端模式
aegis-os cloud subscribe --plan pro --wait
aegis-os cloud up
aegis-os cloud status

# 记忆：导入、配置客户端、启动本地服务
aegis-os memory setup claude --vault ~/Notes
aegis-os memory ui
aegis-os memory pending
aegis-os memory approve <request-id>
aegis-os memory audit
aegis-os memory revoke <session-id>

# 多 Agent：A2A task 与任务看板
aegis-os ipc request --to worker --subject "Review auth" --message "Read the auth module"
aegis-os a2a board
aegis-os a2a show <task-id>

# 任务级租约（高级）
aegis-os policy lease --action-pattern workspace_commit --ttl-secs 3600 --task-id <task-id>

如果使用自定义 --runtime-dir，a2a board、a2a show、memory revoke 等命令要传同一个 runtime 目录。
