01 / QUICK INSTALL

30 秒安装 Aegis OS

支持 macOS 与 Linux。安装后运行一次 aegis-os install 即可自动接入 claude、codex 与 agy，本机沙箱永久免费。完整多 Agent 与云端工作流请查阅 使用教程 →

# 方式 A：Homebrew（macOS & Linux）
brew tap heurion-org/aegis-os https://github.com/heurion-org/aegis-os.git
brew install aegis-os
aegis-os install

# 方式 B：一行签名校验安装脚本（自动完成 aegis-os install）
curl -fsSL https://heurion.org/aegis-cloud/install.sh | sh

# 开启 64GB 云端工作区（免费赠送 1 个云端工作区体验）
aegis-os cloud up
