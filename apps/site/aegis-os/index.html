FLAGSHIP 02 · RUST · TRANSACTIONAL MULTI-AGENT OS

Aegis OS
面向多 Agent 并行的安全控制平面

Aegis OS 让多个 coding agent（Claude Code、Codex、AGY）安全并行：每个 Agent 拥有独立的 CoW 影子工作区与内核沙箱， 通过 Google A2A 协作，通过 UOMP 请求用户记忆，并支持一键将重型编译与多分支任务卸载至 64GB 云端工作区。

01 / ISOLATION

CoW 工作区与沙箱隔离

每个 Agent 独占 APFS clonefile / Linux FICLONE 毫秒级写时复制影子工作区与内核沙箱，沙箱内读写测试 0 弹窗打扰。

02 / COLLABORATION

Google A2A 实时协同

内置 AgentCard 服务发现、Task 状态机、文件预声明锁（coord_claim）与 4 级 LCS Diff3 自动合并，消除多 Agent 覆写冲突。

03 / CONSENT & TOTP

宿主边界审批与记忆授权

落盘宿主机（workspace_commit）强制经过人工审批或独立手机 TOTP 验证；UOMP 个人记忆按 tag / key 最小粒度授权与随时撤销。

01 / SYSTEM ARCHITECTURE

全链路三阶段架构

从本地终端/IDE 智能体接入，经由 Aegis OS 微内核完成策略治理与跨 Agent 协同，按需运行于本机内核沙箱或 64GB 云端隔离节点。

03 / QUICK INSTALL

30 秒安装 Aegis OS

brew tap heurion-org/aegis-os https://github.com/heurion-org/aegis-os.git
brew install aegis-os
aegis-os install

# 方式 B：一行签名校验安装脚本（自动完成 aegis-os install）
