# Heurion 2.0 前端 Mock

实现 S 线与 M1 相关前端时，请以这份 Mock 为布局、状态和交互的参考。

- **源文件**：`workbench.dc.html`（Design canvas 的 `.dc.html` 格式，依赖 canvas 运行时，不能直接在浏览器打开；用来查看结构、样式 token、示例数据和状态逻辑，`renderVals()` 里就是全部状态与数据）
- **设计依据**：[DESIGN_S_SERIES.md](../DESIGN_S_SERIES.md) §5（前端形态）、§4（统一编辑框架）、§7（引用规范）
- 可交互版本在 owner 的 Design canvas 中，未公开；实现以本目录源文件与本说明为准，需要演示时向 owner 申请。

## 布局

三栏：文档列表（248px）｜编辑 / 评审面（自适应）｜协作面板（372px：评论 / 聊天 / 版本 / 引用 + 底部输入框）。

## 样式 token（与设计文档 §5 一致）

| 用途 | 值 |
|---|---|
| 底色 / 面板 / 分割线 | `#F3F4F6` / `#FFFFFF` / `#E5E7EB` |
| 正文 / 次要文字 | `#111827` / `#4B5563` |
| AI 强调色（锚点、AI 回复、修改） | `#2F4FD8`，浅底 `#EEF1FD` |
| 新增 / 删除 | `#15803D`（浅底 `#E8F5EC`）/ `#B42318`（浅底 `#FDECEA`） |
| 锚点漂移 | 文字 `#6B3E00`，浅底 `#FEF3E2` |
| 字体 | 界面 IBM Plex Sans + Noto Sans SC；Word 正文 Noto Serif SC；id / 工具名 IBM Plex Mono |

Mock 中的文字与数据均为示例；实现时以真实接口数据为准。
