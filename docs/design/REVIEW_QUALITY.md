# 深度审稿质量与自演进

> 状态：第 1 步已实现（2026-11-13）；第 2、3 步待做。

## 1. 原则

不另跑固定测试集。质量数据来自**每一次真实审稿**与**医生对每条意见的处理**；自演进的改动只在提出时，用这些数据回放验证后才生效。

起因：2026-11-11 一次为论文实验做的改动让线上默认模型关闭了深度思考，深度审稿两天里只做了表面核查，系统没有任何报警，是用户凭感觉发现的。

## 2. 第 1 步：记录（已实现）

| 记录 | 内容 | 位置 |
|---|---|---|
| 每次审稿 | 耗时；按阶段（通读、规则核查、逐章节审稿、全文复核、合成）的调用次数与 token；模型；是否开着深度思考；覆盖范围；意见数；复核删掉的意见数；出错原因 | 表 `review_runs` |
| 每条意见 | 类别、严重度、来源（规则 / 模型）、所在块、产生时的版本、结局 | 表 `review_findings` |

- 用量按阶段归类：`harness/complete.ts` 的 `withUsageScope`（AsyncLocalStorage），审稿范围内的全部模型调用（含并发）都记进来，不改调用方签名。
- 意见结局：医生「采纳修改」「驳回」都经 `evolveFromReviewComment`（自演进 A、B 两轨的同一入口），在那里记下；其余在统计时按批注现状推断——已解决且锚定的块在意见之后被改过 = 采纳（隐式），已解决但没改 = 不了了之，开着 = 未处理。
- **只存统计与类别，不存稿件原文。**
- 覆盖范围（`ReviewCoverage`）：审了几个章节、跳过了哪些（样板章节、核查力度为「轻」的引言）、核对了几张表、有没有用模型、有没有全文复核；审稿结束时告诉用户。没检出问题时不再说「全文自洽」，只说没有检出并附覆盖范围。
- 进度：审稿改为后台任务（`POST /api/docs/:id/deep-review?async=1`），界面轮询 `GET …/deep-review/jobs/:job` 显示每一步；AI 调用时仍同步。
- 全文复核调用失败以前无声无息（那一批意见未经复核照常报出），现在计数并提示用户。
- 管理员面板「平台运营 → 审稿质量」（`GET /api/admin/review-quality`，AI 经 `platform_admin.review_quality`）：中位耗时、每千字输出 token、每千字意见数、深度思考占比、覆盖范围、意见结局与精确率（下限：明确表态的意见里被采纳的比例）、按类别、每天走势。
- 退化告警（`detectRegression`）：最近 3 次完成的审稿与之前 14 天（至少 5 次）的中位数比，每千字的耗时、输出 token、意见数有两项低于基线 40%，或深度思考从开着变成关着 → 邮件告警管理员（一小时最多一封）。

做这一步时发现并修了一个老问题：样板章节的正则要求词尾边界，「Acknowledgements」「Ethics」「Data availability」「Competing interests」「Abbreviations」都匹配不上，一直被当正文送去模型审稿。

## 3. 第 2 步：漏报信号（待做）

召回率不能只靠医生的操作测：没报的问题医生不会去处理。补这几种信号：

1. 「漏报」按钮：医生指出「这里有问题但没被发现」（最干净）；
2. 审稿后医生在没有意见的位置改了数字或句子（疑似漏报，噪音大，看趋势）；
3. 医生自己加的、指出错误的批注；
4. 同一段文字没变、后一次审稿报出了前一次没报的真问题（相对召回）。

## 4. 第 3 步：演进前回放验证（待做）

参考 Veritas（arXiv:2611.13336，自动生成验证器的框架，离线迭代，不是线上学习系统）里可借鉴的几条做法：

- **一次只改一处**：每个演进提议（一条豁免规则、一处提示词、一次模型配置变更）单独验证。
- **分开学习集与验证集**：从中学到规则的批注不能拿来验证这条规则；按文档（最好按用户）划分，避免同一篇稿件同时出现在两边。
- **只有在验证集上不变差才保留**，否则维持现状。验证集由医生确认过的真问题（必须仍报出）与驳回过的误报（不应再报）组成；按文档聚类做配对检验，并做一次确认回放。
- **泄漏检查**：提议里不能出现具体稿件的内容（现有的数字与专科示例清洗已部分做到）。
- **学习与评分分离**：生成提议的过程看不到验证集的结论。

回放需要保存确认过的意见所在的稿件片段：需要用户或机构同意，默认只存统计。

Veritas 报告其主要误差是「误拒」（把对的判成错）；对我们对应的是全文复核把真问题删掉，回放时要单独统计复核删掉的真问题。

## 5. 局限

医生操作测到的精确率是下限估计（没处理的不计入），召回率只能测到下限。论文二需要的真实召回率，仍要由临床医生对一批稿件做一次完整标注。
