3. ABSTRACT (Single Continuous Paragraph, NO Newlines, NO Extra Whitespace, NO LaTeX Commands):
Agent-Computer Interfaces (ACIs) have transformed autonomous software engineering by replacing raw shell manipulation with structured, lint-guarded code editors. However, scientific and clinical manuscript co-authoring still relies largely on free-form file scripting (e.g., rewriting Office Open XML .docx archives via python-docx or Markdown round-trips). In collaborative workflows, this paradigm suffers from three structural failure modes: (1) editing even a single phrase in a paragraph strips intra-paragraph publisher XML constructs such as EndNote complex citation fields (ADDIN EN.CITE), dynamic numbering fields, footnotes, inline equations, co-author tracked changes, and threaded comment anchors; (2) document-level optimistic version checks (ETag/base_rev) fail in multi-turn sessions when an agent obtains a fresh revision on one paragraph and blindly overwrites an unread clinician edit or deletes a clinician-corrected statistical figure in another; and (3) file snapshots cannot selectively undo an earlier AI turn once a human co-author edits a different clause inside the same paragraph. We present the Heurion Agent-Document Interface (ADI), a collaborative document engine built on three mechanisms. First, a Dual-Surface CRDT Core (ProseMirror + Yjs) projects a live rich-text editor for human authors and a compact Annotated Markdown view for AI agents with persistent block IDs ({#id}), 2D logical table coordinates, atomic citations ([@c:id]), opaque Word field/footnote atoms ([@w:id]), and comment anchors ({#c:id}). Second, Multi-Granularity Pre-Write Contracts pair side-effect-free pre-flight validation (doc_validate) with per-block read-horizon tracking (noteSeen), clinician-delta protection, lock-free intra-paragraph phrase commuting (replace_text), and a two-tier Selective AI Turn Undo (revertTurn) spanning in-memory CRDT transaction origins and cold-restart SQLite fallback. Third, an Intra-Paragraph Token-Patched OOXML Engine (docx-patch) writes untouched blocks byte-for-byte from a raw slice cache (node_src) while surgically patching only altered character runs inside modified paragraphs to keep surrounding Word fields, equations, bookmarks, tracked revisions, and threaded comments (w15:paraIdParent) intact. Evaluated across 19 open-access 2025 PubMed Central full-length clinical manuscripts (150,152 words, 2,719 AST blocks across 7 study designs), Heurion ADI preserves 100.0% byte identity across all 2,553 untouched blocks and 100.0% (114/114) of publisher XML constructs inside edited blocks---compared to 0.0% for Markdown re-serialization and 16.7% (19/114) for pPr-preserving XML paragraph scripts---at median latencies of 2.9 ms for validation, 5.3 ms for selective undo, and 15.5 ms for patched .docx export, while achieving 100.0% accuracy across all 8 deterministic co-editing and out-of-order undo scenarios (152/152 trials). In a live multi-turn agent evaluation (171 episodes driven by deepseek-v4-flash at T=0), Heurion ADI achieves 100.0% (57/57) end-to-end task and OOXML fidelity---versus 33.3% (19/57) for direct OOXML LLM editing (with 4.3x fewer output tokens and 3.2x lower latency on clinical table edits) and 0.0% (0/57) for document-ETag MCP---autonomously self-repairing 100.0% (14/14) of mid-session clinician edit conflicts within the same turn.
