3. ABSTRACT (Single Continuous Paragraph, NO Newlines, NO Extra Whitespace, NO LaTeX Commands, < 1,920 characters):
Autonomous large language model (LLM) agents often edit documents via shell scripts and post-hoc file checks. In clinical research authoring, this workflow risks corrupting Office Open XML (.docx/.pptx) formatting, overwriting concurrent human edits, inserting unverified bibliographic IDs (DOIs/PMIDs), exposing Protected Health Information (PHI), and repeating guard failures across sessions. We present Heurion 2.0, a clinical authoring platform combining a Contract-Guarded Dual-Surface Architecture with a Three-Layer Self-Evolving Memory System. A shared CRDT core (ProseMirror + Yjs) with stable block IDs projects a rich-text editor for clinicians and a guarded Annotated Markdown surface for AI agents with per-turn undo and original-slice OOXML export. Pre-write guards block unregistered citations, a two-stage PHI funnel pairs checksum/regex validators with a pre-masked local 1.5B model (qwen2.5:1.5b) and symbolic output filtering, and runtime guard/revert signals feed a utility-ranked procedural memory store isolated from declarative preferences. Across 1,286 analysed live LLM turns on 10 PMC manuscripts and 680 guard test records, Heurion 2.0 achieved: (1) comparable completion (93.8% vs. 95.1%, p=1.00), 0 vs. 4 content-corrupted untouched paragraphs (p=0.125), and 100% (9/9 vs. 0/9, p<0.0001) comment resolution in .docx editing (162 turns); (2) 98.6% (710/720) synthetic PHI recall (100% on 600 structured spans in Stage 1; 91.7% on 120 narrative spans in Stage 2) and 0/30 unconfirmed destructive tool executions (45 turns total); and (3) in a pre-specified 8-seed, 5-session ablation (1,079 turns), a directional 49% reduction in guard rejections on the primary mixed model (RR=0.51, Holm p=0.1089; NB2 sensitivity RR=0.50, Holm p=0.0269) and a 37% reduction in total execution signals (RR=0.63, Holm p=0.0011).
